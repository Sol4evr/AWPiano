# AWPiano

AWPiano is a playful browser-based piano learning app that teaches songs visually through synchronized sheet music, piano-key highlighting, audio and hand/finger guidance.

## Product modes

- **Watch Song** — demonstrates every note, key and finger in sequence.
- **Start Practice** — waits for the learner to play the correct key before continuing.

## Hardened baseline

The approved initial production baseline is documented in `BASELINE.md` and preserved on branch `baseline/v1.0.0-hardened`.

## Deployment

Production is deployed on Vercel under project `awpiano` and linked to this GitHub repository.
