# AWPiano hardened immutable baseline

Baseline: `AWPiano v1.0.0-hardened`
Established: 5 September 2026 (Australia/Sydney)

This baseline captures the approved product state with:
- full-song sheet music
- live note highlighting and automatic score tracking
- animated piano-key playback
- left/right hand and finger guidance
- Watch Song and Start Practice modes
- tempo control
- song library
- polished child-friendly interface
- AWPiano product branding and app icon

Future development should branch from this baseline. The `baseline/v1.0.0-hardened` branch should not be modified after creation.
